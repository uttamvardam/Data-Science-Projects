2. [Health Insurance Premium Prediction](https://github.com/uttamvardam/Data-Science-Projects/tree/main/Insurance-Premium-Prediction)

  **Description:**
Developed an end-to-end Machine Learning solution to predict annual health insurance premiums using customer factors such as age, BMI, smoking status, income, medical history, and insurance plan. The project includes data preprocessing, feature engineering, model selection, hyperparameter tuning, and Streamlit deployment.

**Technologies Used:**
Python, Pandas, NumPy, Matplotlib, Scikit-learn, XGBoost, Joblib, Streamlit

**Results:**
Achieved **98.87% R²** for customers aged 18–25 using Linear Regression and **99.71% R²** for customers aged 26–72 using Tuned XGBoost. The model was successfully deployed as a real-time Streamlit application.

# 🧠 Deep Learning

1. [Vehicle Damage Detection](https://github.com/uttamvardam/Data_Science_Projects/tree/main/Vehicle%20Damage%20Detection)

  **Description:**
    Built a deep learning-based vehicle damage detection system using ResNet50 to classify car         images into six damage categories.

  **Technologies Used:**
    Python, PyTorch, Torchvision, ResNet50, Streamlit, Pillow (PIL)

  **Results:**
  * Achieved **~80% validation accuracy**.

  * Deployed as a **Streamlit web application** for real-time predictions.
